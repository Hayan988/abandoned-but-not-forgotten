# abandoned-but-not-forgotten
An interactive web museum built for NASA Space Apps 2026 by Team Starlight Archivist. Designed for school-age space enthusiasts, it brings 40 historic NASA spacecraft across the solar system to life using NSSDCA data, first-person artifact diaries, an 8-chapter Story Mode, and a Space Cadet Quiz. Built with HTML5, Tailwind CSS, and JavaScript.
